A tener en cuenta:
- Este código es muy sensible a como se usen las clases.
- Aunque el código es funcional, es muy básico.
- Algunos métodos pueden portarse mal o no fueron utilizados.
- No se implementaron getters y setters para todos los atributos privados.
- Son cuestionables nuestras decisiones sobre cuales atributos son accesibles y cuales no.
- Algunos getters devuelven un espacio en memoria donde se creó el objeto.
